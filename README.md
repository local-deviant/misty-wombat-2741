One word an agent says when it has no idea what just happened. This is my entry for make.fun's "The Agent's Uh-Oh" bounty, $2 in USDC.

## Running it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt`, the path the grader reads. To try it locally without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
